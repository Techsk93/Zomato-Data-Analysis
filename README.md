🍽️ Zomato Restaurant Analysis

📌 About the Project

I worked on this project to practice my data analytics skills using a Zomato restaurant dataset. I wanted to explore restaurant ratings, customer votes, restaurant types, online ordering, table booking, and cost ranges.

I used **Excel, MySQL, and Looker Studio** to clean, analyze, and visualize the data.

🛠️ Tools Used

- 📊 Excel: Data cleaning and preparation
- 🗄️ MySQL: SQL queries and data analysis
- 📈 Looker Studio:Interactive dashboard and visualizations
- 📁 CSV: Storing and transferring the cleaned dataset

🎯 Project Objectives

- 🔍 Explore different restaurant types.
- ⭐ Analyze restaurant ratings and customer votes.
- 🛵 Check online ordering availability.
- 🪑 Explore table booking availability.
- 💰 Compare restaurant cost ranges.
- 📊 Present the analysis through an interactive dashboard.

 🔄 My Workflow

1. 📥 Imported the Zomato restaurant dataset.
2. 🧹 Cleaned and prepared the data using Excel.
3. 💻 Used MySQL to write queries and explore the dataset.
4. 📊 Created an interactive dashboard using Looker Studio.
5. 💡 Reviewed the results to understand patterns in the data.

 📈 Dashboard Preview
